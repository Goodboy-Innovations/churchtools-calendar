# ChurchTools Calendar

Show your [ChurchTools](https://church.tools) calendar on your church website. Works with **WordPress** and **HubSpot CMS**.

- Month calendar with event details, images, locations and links
- Upcoming-events list for TV screens and info boards (WordPress)
- Finnish and English
- Uses your website's font, colors can be changed with a few lines of CSS
- Works on phones
- Free and open source (MIT)

## Get started

1. **Download** the latest release for your website from [Releases](https://github.com/Goodboy-Innovations/churchtools-calendar/releases):
   - WordPress: `churchtools-calendar-wordpress-<version>.zip`
   - HubSpot: `churchtools-calendar-hubspot-<version>.zip`
2. **Follow the [User Guide](docs/GUIDE.md).** It covers the ChurchTools settings, installing, changing the look and troubleshooting.

In short, you need:
- a public calendar in ChurchTools and its ID
- your website's address added to ChurchTools' CORS list (System settings → Integrations → Cross-Origin Resource Sharing)
